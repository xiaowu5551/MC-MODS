# 背包火把与不死图腾（Fabric 1.20.1）

解决副手在火把、盾牌、不死图腾之间反复横跳的问题。

## 功能

1. **背包火把照明**：火把、灯笼、海晶灯、荧石等一切被 LambDynamicLights
   认定为光源的物品，放在背包（主物品栏 36 格）里也会发出移动光源，
   不需要拿在手上。实现方式是扩展 LambDynamicLights 自己的
   `getLivingEntityLuminanceFromItems` 亮度计算管线，因此：
   - 完全复用 DLL 的光源数据与亮度值（模组火把等自定义光源同样生效）；
   - 尊重 DLL 的客户端配置开关与渲染方式（含水下熄灭等规则）；
   - 未安装 DLL 时模组不会崩溃，仅该功能不生效（图腾功能与 DLL 无关，照常工作）。
2. **背包不死图腾**：致命伤害时，如果双手都没有图腾，会按原版语义消耗
   背包（主物品栏，含快捷栏）里的第一组不死图腾：回到 1 点生命、清除
   负面效果、附加原版同款 再生 / 吸收 / 防火效果，图腾弹出动画、音效、
   "图腾保护"进度与统计全部照常触发。
   - 与原版一致：`/kill`、虚空等无视不死性的伤害无法被背包图腾挡下；
   - 手持图腾优先级不变：手上拿的是图腾时按原版走，本模组不插手。

## 安装

- 游戏版本：Minecraft Java **1.20.1**，Fabric Loader（建议 0.15+）。
- 前置模组：
  - **LambDynamicLights**（功能一需要；Modrinth 上 1.20.1 可用版本为
    2.3.x 或 4.4.0+1.20.1，本模组兼容两者。4.x 的 SpruceUI 等库由它自带，
    无需额外安装）。
  - Fabric API：本模组自身不依赖，未列入前置（装了也不冲突）。
- 把 `mod_46937b35-1.0.0-r2.jar` 放进 `mods` 文件夹即可，客户端与服务端
  都可用：光源效果是客户端表现；图腾在服务器端结算，多人游戏同样生效。

## 更新记录

- **1.0.0-r2**：修复"把火把放进物品栏导致游戏崩溃"。原因是背包光源的
  Mixin 注入点漏写 `cancellable = true`：火把只在背包、手上空着时，
  `setReturnValue` 内部会 `cancel()` 一个不可取消的注入，抛出
  `CancellationException` 并从客户端实体 tick 传播出来直接崩游戏。
  现已声明可取消，并给整个处理器加了硬兜底——任何未预料的异常只会静默
  停用背包光源功能，不再可能拖垮游戏。
- 1.0.0-r1：首个版本。

## 实现说明

| 文件 | 作用 |
| --- | --- |
| `mixin/LivingEntityTotemMixin` | `@Inject(TAIL)` 原版 `LivingEntity#tryUseTotem`，背包兜底触发 |
| `mixin/LambDynLightsBackpackLightMixin` | `@Pseudo` Mixin DLL 客户端亮度计算，遍历背包查光源亮度（反射调用 DLL，编译期零依赖） |
